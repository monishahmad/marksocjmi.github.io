# The Marketing Society JMI

A responsive, single-page website for **The Marketing Society (TMS), Jamia Millia Islamia**, designed to introduce the society, showcase its work and leadership, highlight student development opportunities, and help visitors connect or apply.

## About the Society

The Marketing Society works on marketing consultancy and social media management for brands, NGOs, and local businesses. It also helps JMI students build practical experience through live projects, workshops, and case competitions.

## Website Features

- Editorial-inspired visual identity with a dark palette and oxblood accents
- Responsive layout for desktop, tablet, and mobile screens
- Light/dark theme toggle
- Society overview and services
- Work and project highlights
- Executive Board 2026–27 profiles
- Skills and marketing tools section
- Recruitment information and application links
- Contact details with email and Instagram links
- Campus location information for Gate No. 7, Jamia Millia Islamia
- Embedded map and directions link, where configured
- Interactive navigation and subtle motion effects
- Accessibility-conscious controls and reduced-motion support

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts

The page is designed as a standalone HTML file and does not require a package manager or build step.

## Getting Started

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/<your-username>/<your-repository>.git
   ```

2. Open the project folder.
3. Open `index.html` in a browser.

Alternatively, use a local development server such as VS Code Live Server.

## Deployment

You can publish the static website using **GitHub Pages**:

1. Push the website files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch (usually `main`) and the root (`/`) folder.
5. Save. GitHub Pages will provide a public website URL after deployment.

Make sure the homepage file is named `index.html` and is located in the published directory.
